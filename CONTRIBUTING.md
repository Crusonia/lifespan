# Contributing

Thank you for helping. The most valuable contributions are the ones that prove us wrong.

## Ways to help

| You have... | Do this |
| --- | --- |
| An objection to an assumption, number or grade | Open an [assumption challenge](https://github.com/Crusonia/lifespan/issues/new?template=challenge-assumption.yml) |
| A study, dataset or effect estimate | Open an [evidence submission](https://github.com/Crusonia/lifespan/issues/new?template=evidence.yml) |
| A health plan you want measured | Open a [scoring request](https://github.com/Crusonia/lifespan/issues/new?template=score-proposal.yml) |
| A fix to the text | Open a pull request |
| A modeling change | Contribute to [Demeter](https://github.com/Crusonia/Demeter), the model this benchmark pins |

Discussion is welcome in issue comments. Disagree with the argument, not the person.

## Standards for evidence

- Cite the primary source (paper, dataset, official report), with a link.
- Give the effect size **and** its uncertainty, the population, and the outcome measured.
- Say what kind of study it is, so it can be graded (A–D, see [01 · Scoreboard](docs/01-scoreboard.md)).
- Null and contrary results are as welcome as supporting ones.
- **Never post individual health records or identifiable personal data.**

## Writing style

Plain English. Short paragraphs. Numbers with sources. State assumptions and trade-offs. If evidence is thin, say so.

## Neutrality

This benchmark scores plans; it does not endorse candidates, parties or policies. Contributions that argue for or against a party or candidate, rather than about evidence and measurement, will be closed.
